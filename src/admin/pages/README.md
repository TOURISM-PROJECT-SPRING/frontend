# Admin Pages

Route components for `/admin/*` routes.

- `DashboardPage.jsx` - Overview stats, charts, recent activity
- `DestinationsPage.jsx` - List, create, edit, delete destinations
- `BookingsPage.jsx` - View all bookings, update status
- `UsersPage.jsx` - View users, manage roles
- `CategoriesPage.jsx` - CRUD categories
- `ReviewsPage.jsx` - Moderate user reviews
- `SettingsPage.jsx` - Site configuration
- `LoginPage.jsx` - Admin authentication
