# Custom Hooks

Reusable hook logic.

- `useAuth.js` - Auth convenience hook (useContext wrapper)
- `useFetch.js` - Generic data fetching hook with loading/error states
- `useDebounce.js` - Debounce value for search inputs
- `useLocalStorage.js` - Persist state to localStorage
- `usePagination.js` - Pagination state management
