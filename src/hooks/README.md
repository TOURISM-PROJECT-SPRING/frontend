# Custom Hooks

Reusable hook logic.

- `useManager.js` - Manager-area navigation / routing helpers
- `useResource.js` - Generic CRUD data fetching with loading/error state and refetch
- `useTourPlaces.js` - Tour place list + selection helpers

Admin-specific hooks live in `src/admin/hooks/` (e.g. `useDashboardData.js`).
